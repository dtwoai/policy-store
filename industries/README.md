# Industries

Industry landing pages live here. Each subdirectory is a `README.md` that curates the existing app policies most relevant to a regulatory or business domain (e.g. `healthcare/`, `finance/`, `public-sector/`).

**Industry directories never duplicate policy files.** The canonical policy body always lives under `apps/<app>/<policy-slug>/`; the industry landing page only links to it. See the top-level [README](../README.md#where-policies-live) for the rationale.

No industries are populated yet. To add one, see [CONTRIBUTING.md](../CONTRIBUTING.md).
