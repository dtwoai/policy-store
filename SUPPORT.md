# Support

Where to go, by what you need:

| You want to… | Go to |
| --- | --- |
| **Ask how to use or compose a policy** | [GitHub Discussions](https://github.com/dtwoai/dtwo-policy-store/discussions) |
| **Propose a new policy** (or a change to one) | Open a **Policy proposal** [issue](https://github.com/dtwoai/dtwo-policy-store/issues/new/choose) |
| **Report a non-sensitive correctness bug** | Open a **Policy defect** [issue](https://github.com/dtwoai/dtwo-policy-store/issues/new/choose) |
| **Report a sensitive vulnerability / policy evasion** | Privately, per [SECURITY.md](./SECURITY.md) — do not open a public issue |
| **Report a vulnerability in the DTwo gateway product** | security@dtwo.ai (out of scope for this repo — see [SECURITY.md](./SECURITY.md)) |

## Scope of community support

This is a curated, open catalog maintained by DTwo. Community support is
best-effort through the channels above. The policies are reviewed examples and
starting points, **not warranties** — see the trust model in the
[README](./README.md) and each policy's `description`.

The hosted **DTwo MCP Gateway** (one-click import, tenant drafts, upstream-update
detection, enforcement on every live tool call) is the commercial product; see
[dtwo.ai](https://dtwo.ai).
